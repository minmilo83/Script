# 🖋️ Script Codex：墨影琉璃藏書閣管理指南

歡迎來到專屬於妳的數位聖殿。這份指南將手把手教妳如何擴充藏書，即使不觸碰核心代碼，也能輕鬆新增作品與章節。

---

## 🏛️ 藏書閣結構速覽
在開始之前，請先熟悉妳的領地分佈：
* 📁 **`assets/`**：**【請勿更動】** 存放核心引擎 (`core.js`) 與視覺皮膚 (`style.css`)。
* 📁 **`library/`**：**【主要操作區】** 所有書籍的內容都放在這裡。
* 📄 **`manifest.json`**：**【重要索引】** 藏書閣的總目錄，決定書架上會出現哪些書。
* 📄 **`shelf.html` / `engine.html`**：**【請勿更動】** 這是妳的建築本體。

---

## 📖 步驟一：新增一本全新的書

假設妳想新增一本名為「我的新創作」的書，ID 定為 `my-new-story`。

1.  **建立資料夾**：
    在 `library/` 資料夾內新建一個資料夾，命名為 `my-new-story`。
    * *注意：名稱請使用小寫英文與連字號，不要有空格。*

2.  **建立身份檔案 (`identity.json`)**：
    在 `my-new-story/` 資料夾內新建一個 `identity.json` 檔案。內容格式如下：
    ```json
    {
      "title": "我的新創作",
      "scripts": [
        { "file": "chapter1.txt" }
      ]
    }
    ```

3.  **寫入內容**：
    在同一個資料夾內建立 `chapter1.txt`，開始寫妳的故事。

---

## 📑 步驟二：在書架上顯示這本書

建立完檔案後，妳必須在總目錄登記，書架才會出現圖卡。

1.  打開根目錄的 **`manifest.json`**。
2.  在 `books` 陣列中新增一組資訊（記得前一組結尾要加逗號 `,`）：
    ```json
    {
      "id": "my-new-story",
      "title": "我的新創作",
      "path": "library/my-new-story/",
      "category": "原創小說"
    }
    ```

---

## ✒️ 步驟三：新增章節（續寫故事）

當妳想在現有的書裡加第二章時：

1.  **新增檔案**：在該書籍資料夾（如 `my-new-story/`）下新增 `chapter2.txt`。
2.  **登記章節**：打開該書的 `identity.json`，將新檔案排入隊伍：
    ```json
    "scripts": [
      { "file": "chapter1.txt" },
      { "file": "chapter2.txt" }
    ]
    ```

---

## ✨ 視覺渲染語法（讓文字變漂亮）

本引擎會自動解析 `.txt` 內的特殊符號，請善用以下標記：

| 效果名稱 | 使用語法 | 視覺呈現 |
| :--- | :--- | :--- |
| **系統提示線** | 以 `─` 開頭的文字 | 居中加粗，帶有當前意境色 |
| **角色對白** | 使用「」包圍 | 文字會略微加粗，增加識別度 |
| **內心獨白** | 使用（）包圍 | 文字會變淡且略微縮小，產生深邃感 |
| **數據強調** | 數字後加上 %、次、級、點 | 數字會呈現發光的重點顏色 |
| **段落空行** | 直接空一行 | 產生優雅的行距空間 |

## ⚠️ 避雷針：絕對不要做的事

1.  **不要移動 `engine.html` 或 `shelf.html`**：它們必須留在根目錄，否則會找不到路徑。
2.  **檔名大小寫要一致**：GitHub 對大小寫極度敏感，如果 JSON 寫 `Chapter1.txt` 但檔名是 `chapter1.txt`，會導致載入失敗。
3.  **JSON 逗號要小心**：每一組 `{}` 之間要加逗號，但最後一組的結尾**不可以**加逗號。
4.  **避免多餘路徑**：除非妳在 `identity.json` 裡有寫 `scripts/`，否則不要把 `.txt` 塞進多層資料夾。

## 🛠️ 常見問題排除

* **Q: 書架出現了，但點進去一直顯示「載入中」？**
    * 檢查該書資料夾下的 `identity.json` 是否拼錯字。
    * 檢查 `manifest.json` 裡的 `id` 是否與資料夾名稱完全一致。
* **Q: 換章節時沒有動畫？**
    * 請確保妳的瀏覽器沒有關閉 JavaScript 功能。
* **Q: 數字沒有變顏色？**
    * 請確認數字後面緊跟著 `%`、`級` 等單位，中間不要有空格。
