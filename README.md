# 🖋️ Script Codex V2.0：全自動藏書閣管理手冊

這是一座會「自我生長」的圖書館。妳只需要負責 **創作內容**，剩下的索引、排序與目錄更新，全都交給後台的機器人管理員處理。

---

## 🚀 核心作業流程：極簡三步驟
現在，妳新增內容的流程簡化為：
1. **丟入檔案**（資料夾或 .txt）。
2. **Push 上傳**（提交變更）。
3. **喝口水 (等 10 秒)** ➔ 機器人自動更新，網頁即刻生效。

---

## 📚 圖書管理指南

### 1. 新增一本新書
1. 在 `library/` 下建立一個新資料夾（如 `my-story`）。
2. 在裡面放一個 `identity.json`，內容只需寫最基本的資訊：
   ```json
   {
     "title": "妳的書名",
     "category": "分類名"
   }
   ```
   *注意：不需要寫 `scripts` 陣列，機器人會自動幫妳掃描。*

### 2. 新增或刪減章節
* **新增**：直接在書本資料夾下丟入 `1.txt`、`2.txt`。機器人會按照檔名排序。
* **修改**：直接編輯該 `.txt` 檔案內容，重新 Push 即可。
* **刪除**：刪掉 `.txt` 檔案，機器人會自動從目錄中移除該章節。

### 3. 修改書名或分類
* 打開該書資料夾下的 `identity.json` 修改 `title` 或 `category`。
* Push 後，書架（Shelf）上的資訊會自動連動更新。

## ✨ 文字渲染語法（自動偵測標籤）

妳的引擎會自動解析 `.txt` 內的特定符號，並轉換為「墨影琉璃」風格的視覺外觀：

| 觸發符號 | 效果描述 | 使用範例 |
| :--- | :--- | :--- |
| **`─` (開頭)** | **系統提示線** | `─[ 系統掃描：完成 ]─` |
| **`「 」`** | **角色對白** | `「妳看，這就是自動化。」` |
| **`( )`** | **內心獨白** | `（這一切看起來如此不真實。）` |
| **`數字 + %/次/級`** | **數據高亮** | `同步率 150%`、`修正 3 次` |
| **空行** | **優雅間距** | 段落間空一行，會自動產生呼吸感 |

## 🤖 機器人 (MimiBot) 調度說明
* **工作時間**：每當妳對 `library/` 資料夾進行任何更動並上傳時，機器人就會啟動。
* **它的足跡**：妳會發現 `manifest.json` 與 `identity.json` 的更新時間會自動變更，這代表機器人剛剛來過。
* **故障排除**：如果網頁沒更新，請到 GitHub 的 **Actions** 分頁看是否有「紅色驚嘆號」。若有，請確認 `Settings > Actions > General` 的寫入權限是否開啟。

---

## ⚠️ 建築師的禁忌 (請勿觸碰)
* **不要更動 `.github/workflows/`**：這是機器人的契約書。
* **不要移動 `assets/` 內的檔案**：這是妳的建築骨架。
* **不要刪除根目錄的 `manifest.json`**：這是藏書閣的地基，機器人需要基於它進行修改。
